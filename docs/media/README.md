# Скриншоты и оформление

[← На главную](../../README.md)

Галерея снята с настоящего интерфейса **stealthnet-monitor v0.1.4**, запущенного локально в режиме **«Демо-данные»**. Все показатели, аккаунты, ноды и сообщения на изображениях синтетические. Масштаб демо не является результатом нагрузочного теста.

| Файл | Экран |
|---|---|
| overview.png | Обзор сети: состояние, трафик, онлайн и инциденты |
| map.png | Карта нод, регионы подключений и линии к выбранной ноде |
| monitoring.png | CPU, RAM, диск и сетевой трафик |
| traffic.png | Измерения и распределение трафика |
| telegram.png | Настройка бота и пример уведомления |
| billing.png | Хостер, стоимость и ежемесячная дата оплаты |

Снимки сделаны 15 сентября 2026 года. Боевые адреса, аккаунты и токены в галерею не включены. Для воспроизведения включите демонстрационный режим кнопкой в верхней панели.

Обложка и SVG-навигация продолжают оформление проекта [STEALTHNET SOFTWARE](https://github.com/STEALTHNET-APP/STEALTHNET-SOFTWARE).
