# Реализованная архитектура v0.1.0

- Rust Axum API: сессия владельца, одноразовая регистрация агента, телеметрия, аренда, правила, инциденты, жалобы, Telegram и Remnawave.
- Rust systemd-агент: системные метрики каждые 15 секунд, очередь на диске до 24 часов, идемпотентная отправка, опциональный NDJSON источник наблюдений.
- React/TypeScript: общий shell, таблицы/поиск/фильтры, ECharts, карта Natural Earth, отдельно маркированное демо.
- PostgreSQL в Docker Compose, SQLite для локальной разработки. Общий SQLx Any; таблицы создаются аддитивно при старте. Snapshot объединяет телеметрию и вручную заданные метаданные аренды, чтобы агент не перезаписывал их.
- Caddy завершает HTTPS. PostgreSQL доступен только во внутренней Docker-сети; порт API опубликован лишь на loopback. Процесс API работает без root и с read-only filesystem.
- Фоновый цикл 15 секунд: вычисление правил, Telegram queue/retry. Remnawave синхронизируется каждые 60 секунд; часовой цикл удаляет устаревшие метрики.
- Telegram expiry: сохранённое состояние на правило/сервер/дату, этапы 7/3/1/0; продление обнаруживается по увеличению даты. Обычные правила сохраняют время начала превышения, активный инцидент и время последней отправки.

## Граница текущей реализации

Текущие ограничения пагинации, HWID, DPI, GeoIP, нагрузки и корреляции перечислены в README. Эта версия — проверяемый фундамент для тестовой эксплуатации. Дальнейшее масштабирование требует отдельных API пагинации, агрегированных временных рядов и адаптера журналов Remnawave/Xray. Автоматическое обнаружение всех устройств из сетевых пакетов не обещается.
